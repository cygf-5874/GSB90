# 审查报告：utf8cut 的 UTF-8 边界切分

## 填写口径

- 每条结论用一个二级标题起头，标题写法是 `## 结论 N：<一句话>`，`N` 从 1 递增；结论不少于 6 条。
- 每条结论必须给出四要素，缺一条就不算结论：

  - 文件与行号：`<相对路径>:<行号>`（相对仓库根）
  - 复现命令：一节 bash 代码块，固定两行 —— 一行 `javac`、一行 `java`；
    两行都用单条目 classpath（`-cp out`），不要依赖平台相关的路径分隔符；
    两行会被逐字执行（不经过 shell），所以别用 `&&`、管道或通配符；
    源码里有非 ASCII 注释，`javac` 那行请照 `scripts/build.sh` 带上 `-encoding UTF-8`
  - 实际输出：一节 text 代码块，逐行照抄上面 `java` 那行的 stdout
  - 违反的保证：`第 N 条`（可多条，`N` 取 README「对外保证」的编号 1~8）

- 「实际输出」必须来自真实运行：固定件会重跑你的命令，并与你写的输出逐行比对。
- 全部结论至少覆盖 6 条不同的保证，且不得有两条结论指向同一个 `文件:行号`。

下面只是**格式示例**，不是结论：

````md
## 结论 N：<一句话说明观察到的问题>

- 文件与行号：`<相对路径>:<行号>`
  - 复现命令：
    ```bash
    javac -encoding UTF-8 -cp out -d out repro/Repro.java
    java -cp out repro.Repro <子命令> <十六进制字节>
    ```
- 实际输出：
  ```text
  <逐行照抄 java 那行的 stdout>
  ```
- 违反的保证：第 <N> 条
````
